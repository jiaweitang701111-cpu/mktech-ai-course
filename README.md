## 分享素材

- `share/分享卡.png`（1920×1080）、`share/QRcode.png`：掃碼開啟線上簡報。分享卡由 `tools/share-card.html` 截圖而成。
- `行銷科技與數據分析_簡報.pdf`：176 頁 PDF（不放進 repo）。重新產生：
  `msedge --headless=new --no-pdf-header-footer --print-to-pdf=簡報.pdf "file:///…/index.html?print=1"`
  （這台機器上加 `--virtual-time-budget` 會卡住，不要加。）
  也可以直接在瀏覽器按 Ctrl+P 另存 PDF（版面已設定成一頁一張投影片）。

## 操作

| 動作 | 按鍵 |
|------|------|
| 上一頁／下一頁 | ← → 、PageUp／PageDown、空白鍵，手機左右滑 |
| 目錄（可搜尋標題） | M 或右下角 ☰ |
| 總覽 | O 或右下角 ▦ |
| 跳頁 | G，或直接點頁碼 |
| 全螢幕 | F |

網址後面加 `#35` 可直接開到第 35 頁。

手機上會多一個橘色的「放大」按鈕：投影片放大後用手指拖曳瀏覽，再按一次還原；換頁用下方的 ‹ ›。
iPhone 的瀏覽器不支援網頁全螢幕，所以在 iPhone 上不會顯示全螢幕按鈕。
